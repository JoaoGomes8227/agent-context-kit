# Changelog

## 0.1.0 — 2026-08-12

Primeira entrega pública do Agent Context Kit em `okjpg/agent-context-kit`:

- vault local com raw, SQLite/FTS5, Context Ledger e recibos;
- conector `files` e Fathom read-only (probe antes de gravar chave);
- MCP stdio com `search_context`, `list_recent` e `get_context`;
- instalador Hermes com backup/rollback, skill, Mapa de Contexto, demo seed, doctor e uninstall não destrutivo;
- documentação de instalação, arquitetura, segurança, conectores, roteamento, operação, troubleshooting, aceite reproduzível e [guia para testers](docs/testing.md).
